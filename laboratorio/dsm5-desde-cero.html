DSM-5 desde cero

Comprender la estructura de un manual diagnóstico es el primer paso antes de intentar utilizarlo para analizar casos.

FormatoVideo educativo
PropósitoOrientación y uso inicial

El problema de aprendizaje

Antes de interpretar criterios, era necesario aprender a orientarse.

Para muchos estudiantes, el primer acercamiento al DSM-5 puede resultar abrumador. La extensión del manual, la organización por categorías y la cantidad de criterios pueden hacer que se perciba como un documento que debe memorizarse en lugar de una herramienta que debe aprenderse a consultar.

El video se diseñó para reducir esa complejidad inicial y ofrecer una ruta clara: reconocer las secciones del manual, localizar información relevante y comprender cómo se organiza un criterio diagnóstico antes de pasar al análisis de casos.

Propósito del recurso:
Explicar de manera clara y práctica cómo está organizado el DSM-5, cómo localizar información y cómo utilizar sus principales apartados paso a paso.

Decisiones de diseño

La explicación debía reducir la complejidad sin perder rigor.

El recurso se estructuró para construir una base común antes de pedir análisis diagnósticos más complejos.

Reducir la complejidad inicial

La información se organiza por bloques para que el estudiante avance sin enfrentarse a todo el manual al mismo tiempo.

Explicar el recorrido

El video muestra cómo localizar capítulos, categorías, criterios y apartados relevantes dentro del manual.

Construir una base común

Todos los estudiantes parten de una orientación compartida antes de trabajar con casos y tomar decisiones.

Preparar el análisis posterior

Comprender la estructura permite dedicar la sesión al razonamiento y no a buscar información sin una ruta clara.

Qué habilidades buscaba desarrollar

Usar el manual como herramienta, no como lista de respuestas.

El recurso preparó habilidades básicas para el trabajo posterior dentro del curso.

Orientación

Reconocer la estructura general del manual y sus apartados principales.

Búsqueda

Localizar información relevante sin depender de una lectura lineal.

Interpretación

Distinguir criterios, especificadores y elementos contextuales.

Aplicación responsable

Utilizar el manual como apoyo para argumentar, no para etiquetar automáticamente.

Lo que aprendí diseñando este recurso

Antes de pedir análisis complejos, hay que enseñar a orientarse.

Diseñar este video confirmó que una explicación inicial bien estructurada puede reducir la carga cognitiva de las tareas posteriores. Cuando el estudiante comprende primero cómo está organizado el conocimiento, puede concentrar su atención en interpretar, comparar y tomar decisiones, en lugar de invertir esfuerzo únicamente en localizar información.
Cuaderno de diseño

Comprender la estructura de una herramienta es tan importante como aprender a utilizarla.
