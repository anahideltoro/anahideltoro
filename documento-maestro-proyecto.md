# Documento maestro del proyecto
## Sitio profesional de Anahí Del Toro

Última actualización: 19 de julio de 2026

## 1. Propósito

El sitio debe posicionar a Anahí Del Toro como una profesional que diseña experiencias de aprendizaje con fundamento pedagógico, criterio estratégico y uso significativo de la tecnología.

Idea central:

> No se diseñan recursos educativos; se diseña aprendizaje.

## 2. Arquitectura del sitio

1. Inicio
2. En qué creo
3. Mi enfoque
4. Casos
5. Laboratorio
6. Ideas
7. Sobre mí
8. Conversación

La sección “Recursos” no se incluirá en la primera versión.

## 3. Identidad verbal

**Hero:** Aprender cambia cuando el diseño tiene propósito.

**Subtítulo:** Diseño experiencias de aprendizaje donde la pedagogía guía cada decisión y la tecnología amplía las posibilidades.

**Kicker:** Pedagogía · Diseño · Tecnología

**Tono:** Editorial, claro, profesional, reflexivo y humano.

## 4. Mi enfoque

1. Comprender antes de diseñar
2. Diseñar con intención
3. Experimentar para aprender
4. Evaluar para mejorar
5. Diseñar para decidir
6. Seguir aprendiendo

## 5. Sistema de casos

Cada caso tendrá esta estructura:

1. Hero
2. Ficha del proyecto
3. El reto
4. Mi contribución
5. Decisiones de diseño
6. Evidencias
7. Resultados
8. Lo que este proyecto confirmó
9. Recursos relacionados
10. Caso siguiente

### Casos definidos

- Caso 01: Habilidades del Siglo XXI
- Caso 02: Lengua Extranjera para Bachillerato
- Caso 03: Clasificación de Síndromes y Trastornos Mentales

## 6. Sistema del Laboratorio

Cada recurso tendrá:

1. Portada
2. Descripción
3. Contexto
4. Propósito pedagógico
5. Experiencia completa
6. Recurso incrustado
7. Caso relacionado
8. Recursos relacionados

Cada recurso tendrá una URL propia.

No se mostrará el código fuente. Cuando una actividad provenga de Moodle, se reconstruirá visualmente dentro del sitio para conservar su narrativa, diseño e interactividad.
