- Concepto principal: Diseño del aprendizaje
- Especialidades: Diseño instruccional y tecnología educativa
- Idioma y mercado principal: Español / México

## Reglas para páginas nuevas
Cada nueva página debe incluir:
1. `<title>` único.
2. Meta description única.
3. URL canonical absoluta.
4. Open Graph y Twitter Card.
5. Imagen social absoluta.
6. Datos estructurados JSON-LD.
7. Inclusión en `sitemap.xml`.
